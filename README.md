# Alexandria Slattery — Portfolio

Personal portfolio site for Alexandria Slattery, a full stack engineer specializing in scalable e-commerce solutions.

Built with Next.js (static export), React, TypeScript, Tailwind CSS, shadcn/ui, and Framer Motion.

## Development

```bash
npm install
npm run dev
```

The site builds to static files in `out/` with `npm run build`.

## Editing content

All site content (links, experience, projects, education, skills, and writing) lives in [`lib/constants.ts`](lib/constants.ts). Page copy for the hero and About sections is in `components/home/` and `app/about/page.tsx`.

Based on the [Engineering Student Portfolio](https://github.com/niladri-1/Engineering_Student_Portfolio) template.
